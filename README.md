\# 🎮 Roll-A-Ball



Roll-A-Ball is a 3D beginner Unity game where the player controls a rolling ball to collect items while avoiding obstacles.



This game was built as part of a free Unity beginner course and helped me understand Unity physics, collisions, UI, and C# scripting.



\## 🕹️ Gameplay

\- Control a rolling ball

\- Collect all items

\- Avoid obstacles

\- Win when all collectibles are gathered



\## 🛠 Built With

\- Unity

\- C#

\- Rigidbody Physics

\- TextMeshPro UI
